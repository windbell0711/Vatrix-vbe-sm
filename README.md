# Vatrix-vbe-sm

 Vatrix-vbe-sm是对Pvz一代英文原版中Vasebreaker无尽关卡的python模拟，旨在为程序提供认知游戏的底层框架。Vatrix-vbe使得我们可以在超高算力的帮助下，向vbe可否无尽这一经典命题发起冲锋。

## Simulation

|  模块  |          实现精度          |                       备注                        |
|:----:|:----------------------:|:-----------------------------------------------:|
| 攻防判定 |      严格模拟原版的碰撞箱机制      |                  瞬杀类植物的关键评判标准                   |
| 僵尸移动 |      严格模拟原版僵尸移动算法      |              僵尸移动速度不均是瓜吃一路技术的重大威胁               |
| 子弹受击 | 粗略估计伤害，忽略子弹飞行时间和发射间隔浮动 |              子弹伤害不需要高精度模拟，留有一定余量即可              |
| 栈位理论 |      难以控制，暂时不加考虑       | 栈位是游戏评判的重要因素，但在vbe中仅多僵尸啃食坚果时涉及，此时将考虑最坏情况，优先锁定铁桶 |
| 动画逻辑 |          全部删去          |                 与模拟无关，必要数据抽象成数字                 |


### 僵尸移动算法

#### Constant：

速度参数 $γ$

动画位置 $x_{n+1}$（如撑杆n=36）

动画移动量 $s_n$（$s_n=x_{n+1}-x_n$）

动画进度增量 $δ=0.47γ/Σs$

#### Variable：

时刻 $t \in N$

动画进度 $p(t)=(t+1)δ \mod 1$

当前动画 $i(t)=⌈n×p(t)⌉$（注：实际为$floor(…)+1$）

位移速度 $v(t)=(n+1)δ×s_i(t)$
